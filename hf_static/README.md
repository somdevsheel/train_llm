Browser chat demo for [somdevsheel/kaggle-llm-124m-chat](https://huggingface.co/somdevsheel/kaggle-llm-124m-chat), a 124M-parameter LLaMA-style model pretrained from scratch on FineWeb-Edu and fine-tuned on smol-smoltalk using only free Kaggle T4 GPUs.

The model runs entirely in the visitor's browser with [Transformers.js](https://huggingface.co/docs/transformers.js) (int8 ONNX, ~163 MB, cached after the first load). No server is involved.
